# 리코드 세일즈 스크립트 (복붙용)

기준일 2026-10-12 · 상품: **세팅 패키지 150,000원 1회** (후기 이관 + 대표 후기 3개 선별 + 프로필·상담 버튼 완성, 프로 3개월 포함, 자동결제 없음) · 결제: 계좌이체, 안내는 카카오톡

**원칙 3개**
1. 제품 설명 대신 **내 실제 페이지(recordyours.com/syb2020)를 먼저** 보낸다. "저도 레슨하는 사람"이 유일한 무기다.
2. 첫 메시지에서 가격·기능을 말하지 않는다. 목표는 **15분 통화** 하나.
3. 한 사람에게 최대 3번(첫 메시지 + 후속 2번). 거절하면 바로 멈춘다.

`[ ]` 안만 바꿔서 보내면 된다. 상대 페이지에서 본 것 한 가지(후기 수, 지역, 유튜브 등)를 꼭 넣어야 답장률이 오른다.

---

## 1. 첫 메시지

### 1-A. 아는 사람 (강사 지인, 같은 학원, 전 수강생 중 강사)
```
[이름]쌤, 저 영빈이에요! 요즘 제가 레슨 후기를 링크 하나로 정리해서 상담 문의 오면 먼저 보내고 있는데, 상담이 확실히 편해졌어요.
제 페이지 한번 봐주세요 👉 recordyours.com/syb2020
쌤 것도 제가 직접 세팅해드리는 걸 몇 분만 해보고 있어서요. 이번 주에 15분만 통화 가능하세요?
```

### 1-B. 처음 보는 강사 (인스타 DM, 카톡 오픈채팅)
```
안녕하세요 [이름/상호]님, 저도 [강남]에서 보컬 레슨 하는 영빈이라고 해요. [숨고 후기 97개] 보고 연락드렸어요.
저는 숨고·크몽·카톡에 흩어진 후기를 한 링크로 모아서 상담 문의 오면 먼저 보내는데, 수강생들이 훨씬 덜 망설이더라고요. 제 실제 페이지예요 👉 recordyours.com/syb2020
혹시 상담할 때 "나를 보여줄 링크 하나"가 아쉬웠던 적 있으세요?
```

### 1-C. 후기가 여러 플랫폼에 흩어진 사람 (가장 강한 타깃)
```
안녕하세요 [이름]님! 같은 보컬 트레이너라 반가워서 연락드려요.
보니까 [숨고엔 후기 97개인데 크몽엔 6개]더라고요. 저도 똑같았어서, 플랫폼마다 따로 노는 후기를 한 페이지로 모아서 상담 전에 보내고 있어요 👉 recordyours.com/syb2020
[이름]님 후기도 이렇게 모으면 꽤 셀 것 같은데, 한번 보여드려도 될까요?
```

### 1-D. 필라테스·PT·악기 강사 (보컬이 아닌 경우)
```
안녕하세요 [상호]님, 저는 보컬 레슨을 하면서 '리코드'라는 후기 링크 서비스를 만들고 있는 영빈이에요.
[당근 단골 48명]인 걸 보고 연락드렸어요. 1:1 레슨은 결국 "이 선생님 믿어도 되나"에서 결정되잖아요. 흩어진 후기를 한 링크로 모아서 상담 문의에 먼저 보내는 페이지예요 👉 recordyours.com/syb2020
혹시 상담 문의 받을 때 후기 보여주기 번거로우셨던 적 있으세요?
```

## 2. 후속 메시지

### 2-A. 무응답 3일 뒤 (1회차)
```
[이름]님, 바쁘실 텐데 한 번만 더 여쭤볼게요 🙏
요즘 상담 문의 오면 후기를 어떻게 보여주고 계세요? 캡처를 따로 보내시는지, 하이라이트로 보내시는지 궁금해서요.
```

### 2-B. 무응답 7일 뒤 (마지막)
```
마지막으로 하나만 남길게요. 후기 캡처 몇 장만 보내주시면 [이름]님 페이지를 이렇게 만들어드릴 수 있어요 → recordyours.com/syb2020
필요 없으시면 답 안 주셔도 괜찮아요. 응원합니다!
```
> 상대의 후기를 우리가 옮겨 샘플을 만들지 않는다. 리뷰 취득 주체는 항상 본인이다(CLAUDE.md 불변 규칙). 샘플은 상대가 직접 캡처를 보내준 뒤에만 만든다.

### 2-C. "관심 있어요 / 뭔데요?" 답장이 왔을 때
```
감사해요! 말로 하면 길어서 15분만 통화하면서 제 화면 보여드릴게요.
[내일 오후 2시]나 [모레 저녁 8시] 중에 편하신 때 있으세요?
```

### 2-D. "지금은 괜찮아요" (정중한 거절)
```
네 알겠습니다, 시간 내서 봐주셔서 감사해요!
혹시 하나만 여쭤봐도 될까요? 필요 없다고 느끼신 이유가 [이미 쓰는 게 있어서 / 가격 / 상담이 이미 충분히 잘 돼서] 중에 어느 쪽에 가까우세요? 다음 사람한테 설명할 때 정말 도움이 돼서요.
```
> 이 답은 추적표 `거절 이유` 칸에 꼭 적는다. 70명 뒤에 무엇을 바꿀지는 이 칸이 결정한다.

## 3. 통화 (15분 대본)

**0~3분, 상황 듣기** (말하지 말고 묻기)
- "상담 문의는 주로 어디로 와요? 숨고? 인스타? 카톡?"
- "문의 온 사람한테 처음에 뭘 보내세요?"
- "후기는 지금 어디어디에 있어요? 대충 몇 개 정도?"
- "문의 왔는데 결국 등록 안 한 사람, 한 달에 몇 명 정도 돼요?"

**3~8분, 내 페이지 보여주기**
- 화면 공유로 syb2020 페이지 → "상담 문의 오면 첫 답장에 이 링크를 붙여요. 그럼 '선생님 후기 좀 볼 수 있어요?'라는 질문이 사라져요."
- 대시보드의 "내 링크 성과"(조회수·상담 클릭)를 보여준다. (PR #5가 배포된 뒤부터 보인다. 배포 전이면 이 줄은 건너뛴다.)

**8~12분, 제안 (그대로 읽기)**
```
제가 [이름]님 것도 직접 만들어드릴 수 있어요.
숨고·크몽·카톡에 있는 후기를 캡처만 보내주시면 제가 다 옮기고, 상담에서 제일 먼저 보여줄 후기 3개 골라서, 프로필이랑 상담 버튼까지 완성해서 링크로 드려요.
세팅 패키지 15만 원 한 번이고, 프로 기능 3개월이 포함돼요. 자동결제는 없어요.
레슨 한 명만 더 등록돼도 남는 금액이라고 생각해서 이렇게 정했어요.
```

**12~15분, 마무리**
- 좋다 → "그럼 오늘 캡처 보내주시면 [모레]까지 완성해서 링크 드릴게요. 입금 계좌는 카톡으로 보내드릴게요."
- 고민 → 4번 반론 답변 → 그래도 고민이면 "결과 먼저 보고 결제" 카드(아래)를 쓴다.

## 4. 흔한 반론과 답

**"인스타 하이라이트/리틀리/인포크로 무료로 하면 되잖아요"**
```
맞아요, 저도 하이라이트 쓰고 있었어요. 근데 하이라이트는 인스타 안 하는 사람한텐 못 보내고, 리틀리는 링크 모음이라 후기가 안 보여요.
이건 숨고·크몽·당근·카톡 후기를 한 페이지에 출처랑 같이 보여줘서, 상담 첫 답장에 바로 붙이는 용도예요. 그리고 15만 원은 툴 값이 아니라 제가 대신 다 옮겨드리는 작업비예요.
```

**"15만 원은 좀 비싸요"**
```
레슨 한 달 수강료보다 적게 잡았어요. 이 링크로 상담 온 분 중에 한 명만 더 등록해도 바로 회수되고요.
그리고 제가 직접 다 해드리니까 [이름]님은 캡처만 보내시면 끝이에요. 시간 값까지 생각하면 오히려 싸다고 생각해요.
```

**"숨고/크몽에 이미 후기가 있는데요"**
```
그 후기는 숨고 안에서만 보여요. 인스타나 카톡으로 문의 온 사람한텐 못 보내고, 나중에 플랫폼 수수료 아끼려고 직접 받을 때 그 후기가 다 사라지는 거예요.
리코드는 그 후기를 [이름]님 소유 링크로 옮겨두는 거예요.
```

**"후기 옮겨도 되는 거예요? 문제 없어요?"**
```
[이름]님 본인이 받은 후기를 본인이 직접 캡처해서 올리는 방식이라 괜찮아요. 저희가 플랫폼에 들어가서 긁어오는 건 하지 않고, 페이지에도 어디서 받은 후기인지 출처가 같이 표시돼요.
```

**"생각해볼게요"**
```
네 그럼요. 혹시 고민되는 게 가격이에요, 아니면 이게 정말 상담에 도움이 될지예요?
```
→ "도움이 될지"라면 아래 카드.

**"결과 먼저 보고 결제" 카드 (고민하는 사람에게만, 첫 5명 한정)**
```
그럼 이렇게 해요. 캡처 보내주시면 제가 먼저 다 만들어서 링크 드릴게요. 보시고 상담에 쓸 만하다 싶으면 그때 입금해주세요. 별로면 안 하셔도 돼요.
```
> 무료 체험이 아니라 **결제 순서만 바꾼 것**이다. 완성 후 3일 안에 결제 여부를 꼭 묻는다.
