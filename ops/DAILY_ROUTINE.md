# 데일리 루틴 (AI용 지시서)

어떤 AI 툴이든 이 문서대로 하면 된다 (Claude Code, Aside, Codex, Cursor 등). 먼저 `ops/README.md`의 "절대 하지 않는 것"을 읽는다.

## 매일 아침 (평일, 창업자가 보기 전에)

**입력:** `ops/private/tracker.xlsx` (`명단` 시트), `ops/private/leads.md`, `ops/SCRIPTS.md`, `ops/LEAD_CRITERIA.md`
**출력:** `ops/private/queue/YYYY-MM-DD.md` 하나. 메시지를 직접 보내지 않는다.

1. **오늘의 새 대상 10명 고르기.** 추적표 `명단` 시트에서 K열(1차 연락일)이 비어 있는 사람을 등급 순(A → B → C, 지인 우선)으로 고른다.
   - 10명이 안 되면 `LEAD_CRITERIA.md` 기준(3개 이상 충족)으로 공개 프로필에서 새 후보를 찾아 추적표 빈 칸과 `leads.md`에 추가한다.
   - 하루 새 후보 조사는 20명 이하. 공개 페이지를 사람이 보듯 한 장씩 열고, 숫자·지역·연락 채널만 적는다. 후기 본문 복사 금지.
2. **사람마다 첫 메시지 쓰기.** `SCRIPTS.md` 1-A~1-D 중 추적표 I열에 적힌 것을 바탕으로 쓴다.
   - 첫 줄에 그 사람의 공개 정보 하나(후기 수, 지역, 유튜브, 플랫폼 간 후기 차이)를 꼭 넣는다.
   - 서명은 영빈, 링크는 `recordyours.com/syb2020`. 첫 메시지에 가격·기능 설명 금지. 목표는 15분 통화.
   - 열 개가 같은 문장으로 보이면 안 된다.
3. **후속 대상 뽑기.** 추적표 L열(+3일)이 오늘이고 N열이 아직 `연락함`(무응답)이면 `SCRIPTS.md` 2-A, M열(+7일)이 오늘이고 여전히 `연락함`이면 2-B를 쓴다.
4. **큐 파일 저장.** 아래 형식으로 `ops/private/queue/YYYY-MM-DD.md`에 쓴다.

~~~
# 오늘 보낼 메시지 (YYYY-MM-DD)
할 일: 복사해서 보내고, 보낸 번호를 알려준다.

### 1. [이름/상호] · [지역] · [연락 채널]
근거: [공개 근거 한 줄] · [프로필 링크]
```
[메시지 본문]
```
...
## 후속
### [이름] · 2-A (첫 연락 MM-DD)
```
[메시지]
```
~~~

## 창업자가 "N번까지 보냈어"라고 하면

- 해당 사람의 K열에 오늘 날짜, N열을 `연락함`으로 바꾼다.
- 못 찾아서 건너뛴 사람은 R열 메모에 "채널 못 찾음"을 적고 다음 큐에서 뺀다.

## 창업자가 받은 답장을 붙여넣으면

- 관심 표시 → `SCRIPTS.md` 2-C로 통화 시간 두 개를 제안하는 답장 초안.
- 정중한 거절 → 2-D로 거절 이유를 묻는 답장 초안. 답이 오면 R열에 이유를 적는다.
- 가격·방식 질문 → `SCRIPTS.md` 4절 반론 답으로 초안.
- 결제 의사 → 5절 결제 안내. 계좌 정보는 창업자가 채운다.
- N열 상태를 드롭다운 값(`답장` / `통화 잡힘` / `통화함` / `결제 대기` / `결제 완료` / `거절` / `무응답 종료`) 중 하나로 갱신한다. 2-B까지 보내고 답이 없으면 `무응답 종료`.

## 매주 일요일

1. 추적표 `요약` 시트 숫자로 `ops/WEEKLY_LOG.md`에 한 줄 추가: 이번 주 접촉·관심 답장·통화·결제, 가장 많이 들은 거절 이유, 다음 주 바꿀 것 1개. **이름은 쓰지 않는다.**
2. 이 로그를 리포에 커밋한다 (공개되는 건 숫자뿐).
3. 판정일(2026-11-24)이 지나면 `ops/README.md`의 판정 기준표로 결론을 내고 README "현재 상태"에 적는다.

## 이 루틴이 하지 않는 것

- 메시지 발송, 통화, 입금 확인 (창업자만).
- 새 기능 개발. 판정 전까지는 고객이 직접 요청한 버그 수정만 한다.
